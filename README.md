# TutorConnect

A modern web application for connecting students with tutors. Built with Next.js, MySQL, and Tailwind CSS.

## Features

- User authentication (students and tutors)
- Profile management for tutors
- Session booking system
- Real-time availability management
- Subject-based tutor search
- Dashboard for managing bookings

## Prerequisites

- Node.js 16.x or later
- MySQL 8.x
- npm or yarn
