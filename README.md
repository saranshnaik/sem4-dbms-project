# TutorConnect

A modern web application for connecting students with tutors. Built using **Next.js, MySQL, and Tailwind CSS**.

## Features

- Student and tutor authentication
- Tutor profile management
- Session booking system
- Real-time tutor availability management
- Subject-based tutor search
- Dashboard for managing bookings

## Technologies Used

- **Next.js**
- **MySQL**
- **Tailwind CSS**
- **Node.js**

## Prerequisites

Before running the project, make sure you have:

- Node.js 16.x or later
- MySQL 8.x
- npm or yarn

## How to Run

Clone the repository and navigate to the project directory:

```bash
git clone <repository-url>
cd TutorConnect
```

Install the required dependencies:

```npm install```

Configure the MySQL database and update the project's database configuration as required.

Start the development server:

```npm run dev```

The application will be available at the local development server URL shown in the terminal.

## Project Structure

The project follows a typical Next.js application structure, with the frontend, backend logic, database integration, and styling organized within the project.
